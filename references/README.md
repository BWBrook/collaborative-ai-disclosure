## How to extend this evidence base

Read related frameworks before asserting novelty. Extract authors’ actual declarations as declarations—not proof that all reported safeguards occurred. Distinguish what a paper recommends from what its authors report doing. Retain publication dates separately from the date of your source check, and note corrections. Do not reproduce whole copyrighted papers or policy pages in this repository.

Contributors should add a source record and a concise interpretation with a visible scope. Updating a URL or reading search metadata does not justify marking the full document inspected. None of the source records is an endorsement of this framework by the cited authors or publishers.
