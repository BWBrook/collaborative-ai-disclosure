## Extending the evidence base

Record publication/version dates separately from inspection dates, preserve prior scope when refreshing a record, and identify corrections and retrieval failures. A URL update, abstract or search result is not a full-text reading. Cite precise sections for comparisons and distinguish a framework's provisions from its authors' particular practice. No source record implies endorsement of this project by the cited authors or publishers.
