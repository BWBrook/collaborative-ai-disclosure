# Define proportionate preservation without demanding complete transcripts

The framework distinguishes reproducibility release, development history and deliberative record. Barry welcomed their complementary value while noting that long persistent agent threads are newer and many older projects have incomplete records.

Explore what a useful minimum narrative looks like when dates, models or early iterations are only partly recoverable. Compare a named reproducibility release from the same Git repository with a separate clean export linked explicitly to the development history. Do not recommend destroying the history in order to make a clean release.

Consider protected datasets, unpublished ideas, peer-review material, personal information and secrets before sharing transcripts. A compaction summary should be labelled as a summary; it should not be treated as a complete original conversation. System-private model reasoning is not a required or assumed export.

**Completion:** a proportionate proposal with both strong-record and incomplete-record examples, explicit privacy limits and no fabricated retrospective log.
