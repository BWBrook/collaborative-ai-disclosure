# Example: an embedded computational ecology collaboration

**FICTIONAL. Not a report of an actual study, a completed check or a particular model's capabilities.**

## Illustrative declaration

This project involved governed human–AI collaboration across question refinement, development of the analytical workflow, interpretation and manuscript preparation. AI systems contributed proposals, code, critiques and draft text through repeated interaction with the researchers. Defined computational comparisons were sometimes delegated, but the researchers revisited the framing and consequential methodological choices throughout. Contributions to reasoning and expression were sufficiently intertwined that exclusive ownership of individual ideas or passages is not asserted.

The researchers evaluated the sampling assumptions and inspected the source material supporting the central literature claims. The implementation was tested against simulated cases with known inputs, and the archived analysis was rerun from the documented data release. These checks supported implementation consistency but did not remove the study's limitations in distinguishing the competing ecological mechanisms. AI-assisted criticism informed, but did not replace, the researchers' assessment of those limitations.

The accompanying AI-use account identifies recorded systems and approximate periods. Early model identifiers and some conversations were not retained; the development history is therefore incomplete. The final repository contains the inputs that can be shared, executable code and output mapping. The authors approved the final claims and manuscript and accept responsibility for the work.

## What this example is testing

The declaration is explicit about substantial involvement without reserving writing as a human-only activity. It explains the actual limits of the fictional checks. It does not treat a rerun as proof of causal inference, or missing early conversations as permission to invent a complete model inventory. A real declaration still needs the actual tool names and any venue-required details.
