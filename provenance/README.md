# Origins and decision provenance

This directory preserves the intellectual continuity of the founding discussion without claiming to be a complete transcript export.

The [founding-discussion synthesis](founding-discussion.md) records the substantive points and distinguishes Barry's positions from subsequent assistant proposals. The [decision log](decision-log.md) tracks working commitments and unresolved items. The [original working statement](original-working-statement.md) preserves the initial two-paragraph draft that Barry welcomed. The [coverage map](coverage-map.md) accounts for the themes in the longer initial answer and the subsequent discussion.

The material is curated and retrospectively organised. It does not include unrelated personal information, a raw chat export, hidden model reasoning, or a fabricated sequence of original Git commits. New Git history should begin when this scaffold is imported.

Order is recorded by discussion topic rather than reconstructed exact timestamps. The scaffold and source-check date is 2026-09-08; that is not represented as the date on which all founding conversations occurred.
