# Using the templates

Start with the [concise declaration](declaration-concise.md) or [extended declaration](declaration-extended.md). Write the account that fits the real project, then check the target journal's requirements. There is no obligation to complete every template or to assign contributor roles.

Each file contains a clearly delimited drafting passage and instructions. Replace `{{...}}` fields and remove drafting instructions before submission. Do not paste a placeholder into a journal submission or claim that a suggested check was actually performed.

| Template | Purpose |
| --- | --- |
| [Concise declaration](declaration-concise.md) | A short, factual account suitable for adaptation to a paper |
| [Extended declaration](declaration-extended.md) | More room for the iterative relationship and its limits |
| [Methods disclosure](methods-disclosure.md) | AI involvement that materially affects the research procedure |
| [Repository AI_USE](AI_USE.md) | A readable project-level account, with optional detail |
| [Verification record](verification-record.md) | Record actual evidence for a consequential claim or artifact; discussion draft |
| [Policy check](policy-check.md) | Document a target-journal check without claiming automatic compliance |
| [Decision record](decision-record.md) | Preserve a consequential choice or unresolved issue |

Tool identity, approximate periods, particular functions and human involvement can be incorporated naturally into prose. A small table is optional when it improves clarity. The framework does not mandate a CRediT-style assignment grid.

The templates are deliberately neutral about whether a scientist personally typed the first draft. Do not add “AI only improved the language” unless that is true. Do not assert that humans originated every idea or personally reviewed every intermediate action unless the records support it.

The template-specific verification clauses are **proposals**, not a resolved sixth principle. Their inclusion helps expose what needs discussion; it does not certify a project or settle what adequate assurance means.

The [fictional examples](../examples/README.md) show different ways of filling out a narrative. They are not accounts of Barry's actual research and must not be copied as evidence that checks occurred.
